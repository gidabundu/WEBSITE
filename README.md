# Noir Kitchen

A static, multi-page restaurant website for a modern French dining room in Paris. It uses plain HTML, CSS, and vanilla JavaScript; there is no framework, build step, or package installation.

## Run locally

From the project directory, serve the files with a static web server:

```sh
npx serve .
```

Alternatively, open the folder in Visual Studio Code and use the Live Server extension. A server is recommended so that page navigation and assets behave consistently.

## Project structure

```text
.
├── index.html          Home, experiences, journal, gallery, FAQ, and reservations
├── about.html          Restaurant story, chef, timeline, and team
├── services.html       Menus and private dining
├── 404.html            Not-found page
├── README.md
├── assets/
│   └── README.md        Hero image placeholder note
├── css/
│   ├── styles.css       Shared design system and responsive layout
│   ├── about.css        About-page styles
│   └── services.css    Services-page styles
└── js/
    ├── script.js        Shared navigation, reveals, counters, and controls
    └── services.js     Services-page interactions
```

## Hero image

The hero is styled to fall back to a dark gradient if `assets/hero.png` is absent. See [assets/README.md](assets/README.md) for the expected image dimensions and direction.
